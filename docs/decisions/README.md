# القرارات المحاسبية — تسلسل الاعتماد

> **لا شيء في هذا المجلد تفويض بالتنفيذ.** هذه وثائق مُعدَّة للمراجعة. لا يُطبَّق
> أي قيد محاسبي ولا أي migration مترتب عليها قبل اعتماد مكتوب من صاحب السياسة
> المحاسبية للمنشأة.

## لماذا هذا الترتيب

الترتيب أدناه **ليس** ترتيب الأرقام. الأرقام هويّة ثابتة للوثيقة (كي لا تنكسر
الروابط والمراجع)، والترتيب هنا هو **أولوية الاعتماد**.

المنطق: نحسم أولًا ما قد **يُشوّه القوائم المالية نفسها**، ثم ما يحسم قيودًا
تشغيلية. قرار يغيّر تعريف النقدية أخطر من قرار يحدد من يتحمّل حصة رسوم خدمة، لأن
الأول يمسّ كل تقرير صدر ويصدر، والثاني يمسّ معاملة بعينها.

| الوثيقة | الوضع اليوم | ما يُفتح بالاعتماد |
|---|---|---|
| 0005 | القائمة تعمل وتتوازن؛ حساب واحد متحرك غير مصنَّف | دقة توزيع الأنشطة، ومراجعة الـ134 حسابًا المعلَّمة نقدية |
| 0001 | الضريبة محسوبة ومخزّنة وغير مقيَّدة | تعديل `post_supplier_invoice`، مراجعة الإلغاء، ومسار التوريد |
| 0002 | الميزة معطَّلة (`DEPOSIT_LIABILITY_ACCOUNT_NOT_SET`) | تشغيل دورة الودائع فعليًا |
| 0003 | العمولات تُحمَّل كمصروف فترة | معالجة مختلطة إن لزم، ومسار الإلغاء المفقود |
| 0004 | `handed_over_only` معطَّل افتراضيًا | تفعيله لكل عميل حسب عقده، وربما تحميل المطوّر حصته |

## آلية الاعتماد

كل وثيقة تنتهي بسطر قرار:

```
> **[ ] لم يُحسم بعد.**
```

يُستبدل بالبديل المعتمد واسم المُعتمِد وتاريخه، ثم يُفتح عمل التنفيذ **في تغيير
منفصل** يشير إلى الوثيقة. لا يُدمج قرار مع تنفيذه في تغيير واحد.

## ما لا يحتاج قرارًا

للتوضيح، هذه حُسمت ونُفِّذت ومُختبَرة، وليست معروضة هنا للنقاش:

- الوديعة **التزام لا إيراد** — [قرار 0002](0002-security-deposit-liability-account.md) يناقش الحساب لا المبدأ.
- سداد إيجار متأخر من الوديعة **ليس خصمًا** — لأنه يعترف بالإيراد مرتين.
- العمولة تُستحق **عند التعاقد لا عند السداد** — [قرار 0003](0003-commission-expense-and-payable-accounts.md) يناقش التصنيف لا التوقيت.
- التسليم **لا يُنتج قيدًا** — لا نقد يتحرك.
- توزيع رسوم الخدمة **بطريقة أكبر البواقي** — ضمانة حسابية لا سياسة.
