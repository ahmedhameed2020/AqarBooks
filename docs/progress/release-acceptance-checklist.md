# قائمة اعتماد إطلاق AqarBooks

**التاريخ:** 2026-10-31  
**الحالة:** مسودة للمراجعة والاعتماد؛ ليست إعلان جاهزية للإنتاج.  
**الغرض:** توحيد شروط إغلاق النواقص المعروفة في قائمة واحدة، دون استبدال لوحة التقدم أو أدلة التنفيذ الحالية.

## قاعدة قرار الإطلاق

لا يُعتمد الإطلاق إلا عندما تتحقق الشروط التالية معًا:

1. جميع بنود **البوابات العامة** حالتها «مغلق» ولها دليل مقبول.
2. كل ميزة داخل نطاق الإصدار حالتها «مغلق»، أو استُبعدت كتابةً من النطاق مع تعطيل مسارها وعدم وعد المستخدم بها.
3. لا يوجد P0 مفتوح، ولا P1 مفتوح داخل نطاق الإصدار.
4. اعتماد المالك ومدير الإصدار موثق في سجل التوقيعات أدناه.
5. نجاح محلي أو على r6 لا يُعد وحده اعتمادًا للإنتاج.

**مفتاح الحالات:** مفتوح = العمل أو القرار لم يكتمل؛ محجوب = ينتظر قرارًا أو موردًا خارجيًا؛ مؤجل = خارج النطاق بقرار موثق؛ مغلق = تحقق شرط الإغلاق وقُبل الدليل.
