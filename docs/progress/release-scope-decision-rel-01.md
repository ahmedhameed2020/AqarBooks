# مسودة قرار REL-01 — نطاق إصدار AqarBooks

**التاريخ:** 2026-10-30  
**الحالة:** مسودة غير معتمدة؛ REL-01 يبقى «محجوب».  
**المالك:** مالك المنتج/المالك.  
**المرجع:** `docs/progress/release-acceptance-checklist.md`.

> هذه المسودة لا تمنح موافقة على الاتصال بالإنتاج أو تطبيق ترحيلات أو النشر أو commit أو push. إعدادها أو مراجعتها لا يُعد توقيعًا عليها.

## 1. القرار المقترح

إصدار محاسبي محدود، وليس إطلاقًا عامًا، يشمل القدرات المالية الأساسية الموضحة أدناه، مع استبعاد الميزات غير المكتملة أو التي تنتظر قرارات ومفاتيح خارجية.

**المسار المقترح:** بروفة في بيئة منفصلة أولًا، ثم تجربة إنتاج محدودة بمؤسسة واحدة أو اثنتين صغيرتي الحجم بعد إغلاق REL-02 إلى REL-08. لا تُحدد هذه التجربة من تتأثر بياناته بالترحيلات؛ أثر الترحيلات العام يخضع لـREL-04 وREL-05.

## 2. المؤسسات الداخلة في النطاق

لم تُذكر أسماء أو معرفات مؤسسات في الطلب؛ لذلك تبقى الحقول التالية معلقة ولا تُخمّن.

| الحقل | القيمة المقترحة/المطلوبة | حالة القرار |
|---|---|---|
| المؤسسة الأولى | الاسم والمعرف: **يحددهما المالك** | معلق |
| المؤسسة الثانية، اختياريًا | الاسم والمعرف: **يحددهما المالك** | معلق |
| معيار الاختيار | حجم صغير، بيانات مفهومة، محاسب مسؤول، وقدرة على مراجعة النتائج أثناء التجربة | مقترح |
| المؤسسات التجريبية `is_demo` | لا تدخل في تجربة الإنتاج | مقترح |
| مالك قرار كل مؤسسة ومحاسبها | الاسم وبيانات التواصل تُسجل قبل الاعتماد | معلق |

## 3. الميزات الداخلة في الإصدار المقترح

| المجال | النطاق المقترح | شرط بقائه داخل الإصدار |
|---|---|---|
| التقارير المالية | التقارير والصلاحيات المنفصلة للقراءة المشمولة في حزمة الإصدار | اجتياز الفحوص والصلاحيات واختبار الدخان |
| لوحات المعلومات | دلالة المؤشرات التي غطاها BI-1 فقط | يبقى تحقق r6 دليلًا محليًا، ويُستكمل التحقق ضمن الإصدار دون إعادة فتح BI-1 بلا عيب مثبت |
| المستحقات | إصدار المستحقات بحساب مدينين معتمد وفترة محاسبية مفتوحة | اكتمال إعداد كل موقع ومؤسسة قبل الاستخدام |
| الإيصالات والخزينة | الإيصال فقط على حساب نقدي/بنكي صالح مرتبط بخزينة أو بنك فعّال | اكتمال الربط ونجاح قبول الحساب الصحيح ورفض غير الصحيح |
| التسوية البنكية | الإنهاء الصارم بعد مطابقة جميع الأسطر | مراجعة الكشوف غير المنتهية وغير المطابقة قبل الترحيل |
| السلف | سلف العملاء فقط في مؤسسة اعتمدت حساب الالتزام الخاص بها | استبعاد الرد النقدي وتحويل الرصيد، وحسم حالات انتقال الملكية ذات السلف المعلقة وفق ADV-01 |
| الإشعارات والبوابة البرمجية | إشعارات الحجز ورفض تصريح يخص مؤسسة أخرى | لا يشمل ذلك تشغيل العتاد الميداني |
| الأداء وRLS | التحسينات والسياسات المدرجة في حزمة الإصدار | إغلاق فحوص الأثر والتكافؤ والصلاحيات ضمن البوابات العامة |

## 4. المستبعد من الإصدار المقترح

| الميزة | قرار النطاق المقترح | الإجراء المطلوب قبل اعتماد REL-01 |
|---|---|---|
| «اسأل AqarBooks» | مستبعد حتى إغلاق AI-01 إلى AI-04 | تعطيل مسار المستخدم والتحقق من عدم تقديمه كإجابات موثقة |
| إقفال نهاية السنة ورحلة Batch 2 و3 | مستبعد | إبقاء الوظيفة غير موعودة وضمن CLOSE-01 حتى قرار لاحق |
| الفاتورة الإلكترونية القانونية، ومنها ETA | مستبعد | عدم تقديمها كمسار قانوني فعّال؛ تبقى ضمن TAX-01 |
| Fawry والجوال | مستبعدان | إبقاء التكامل معطلًا وعدم طلب مفاتيح ضمن هذا الإصدار |
| الرد النقدي وتحويل الرصيد بين الأعضاء | مستبعدان | منع تقديم الإبطال على أنه رد، وتطبيق الإجراء المؤقت المعتمد عند انطباقه |
| انتقال ملكية وحدة لها سلفة معلقة | مستبعد ما لم يُغلق ADV-01 | منع الحالة غير المدعومة بوضوح أو استكمال مسار الرد قبل إدخالها |
| العتاد والتشغيل الميداني للبوابة | مستبعد | إبقاء `gate_hardware_settings.enabled = false` ومحول `NOOP` |
| العرض العام/التجريبي | مستبعد | إبقاء الأصل مغلقًا والتحقق من عدم تفعيل أسراره أو مؤسساته ضمن التجربة |
| Accsys | مستبعد | لا يدخل إلا بقرار مستقل موثق |
| تقارير الأصول وCAM وCAPEX/OPEX | مؤجلة وخارج النطاق | إبقاء الروابط مخفية وعدم وعد المستخدم بها |

## 7. شرط إغلاق REL-01

لا يتغير REL-01 إلى «مغلق» إلا عندما:

- [ ] لا توجد حقول «معلق» في المؤسسات والميزات والنافذة.
- [ ] قبل المالك النطاق والمستبعدات كتابةً دون توسيع ضمني.
- [ ] تحقق فعليًا أن الميزات المستبعدة معطلة أو غير متاحة للمستخدم.
- [ ] وُثق أن نطاق المستخدمين لا يحد أثر الترحيلات العام، وأن REL-04 وREL-05 يعالجان ذلك.
- [ ] سُجلت موافقة الإنتاج المنفصلة، بعد استيفاء بقية البوابات، في سجل الاعتماد.
