# مراجعة أمنية — مسارات Server Actions والأسرار (تكملة البند 9)

**التاريخ:** 2026-11-01 · **الوضع:** قراءة فقط، تحليل ساكن + فحص جرد. **ليست مراجعة بشرية مستقلة.**

## المنهج
- جرد `lib/actions/` (‏56 ملفًا، ‏214 دالة مُصدَّرة).
- تصنيف كل ملف: تحقق تطبيقي (`proveTenantPermission`/`hasPermission`/`getCurrentUser`)، عميل مستخدم + RLS، RPC ذاتي الحراسة، أو عميل admin (يتجاوز RLS).
- فحص حدود العميل/الخادم: أي مكوّن `"use client"` يستورد `lib/supabase/admin` أو `lib/env/server` أو `server-only`.
- فحص استخدام الأسرار: `process.env` للمفاتيح الحساسة وموضع قراءتها.

## النتائج

**1) ملفات عميل admin (12):** عشرة منها تحمل تحققًا تطبيقيًا صريحًا (‏`proveTenantPermission`/`hasPermission`). الاثنان الباقيان مراجَعان سطرًا بسطر:
- `leads.ts`: نموذج عام (بلا جلسة بالتصميم)؛ الجداول بلا سياسة INSERT للعميل، والخدمة-الدور هي الكاتب الوحيد؛ honeypot + حد معدل في القاعدة (إرسال واحد/ساعة/بريد). **مقبول.**
- `member-portal-documents.ts`: يستخدم admin لأن سياسة مالك البوابة لقراءة مستنداته غير موجودة بعد؛ التفويض في الكود عبر `getPortalMemberContext()` (صف العضو من الجلسة)، وكل استعلام مقيّد بـ`member_id` و`organization_id`، ومعرّف المستند يُعاد التحقق منه، والرابط الموقّع 300 ثانية. **مقبول مؤقتًا** — يبقى دين تقني موثق: سياسة RLS + سياسة تخزين عند إعادة فتح الترحيلات.

**2) ملفات بلا تحقق على مستوى الملف (32):** تعتمد على عميل المستخدم (‏RLS) و/أو RPCs من نوع SECURITY DEFINER ذاتية الحراسة (`has_permission`/عضوية/حراسات الفترة). نقطة فحص عينات: `treasury.ts`، `accounting.ts`، `einvoice-settings.ts` — كلها تمر عبر عميل المستخدم + RPC محروس. **لا مسار كتابة مباشر بلا RLS أو حارس RPC.**

**3) حدود العميل/الخادم:** صفر مكوّن `"use client"` يستورد وحدات الخادم (`admin`/`env/server`/`server-only`).

**4) الأسرار:** مفاتيح الخدمة/المزودين تُقرأ فقط في وحدات خادم (`lib/env/server.ts`, `lib/ai/config.ts`)؛ لا مفاتيح مضمّنة في الكود، ولا `NEXT_PUBLIC` لمفتاح خدمة.

## ما لم يُغطَّ
- ليست مراجعة سطرًا بسطر لكل 214 دالة؛ الاعتماد على تصنيف + عينات + حراسة RPC.
- لا اختبار تخريبي/تزوير جلسات حي (fuzzing).
- إعدادات منصة Supabase (Auth/Storage/حدود المعدل) خارج النطاق.
- **المراجعة البشرية المستقلة تبقى مطلوبة** لإغلاق البند بمعناه الحرفي.

## الحكم
لا BLOCKER/IMPORTANT في هذا النطاق. الفجوة الوحيدة الموثقة: تفويض تطبيقي مؤقت لمستندات البوابة ينتظر سياسة RLS.
