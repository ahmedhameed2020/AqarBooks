# حزمة المراجعة (r6 فقط؛ لم يُطبَّق شيء خارج r6)

## ما في الحزمة
- sql/: الترحيل النهائي لحماية المشاريع (20261029120000)، وترحيل قفل السطر وحد WIP (20261029130000)، وخطة التراجع، والبصمات (قبل/بعد/بعد التراجع)، ومخرجات التطبيق.
- code/: فرق صفحة العقود (الاسم والهاتف)، وفرق الخيار A (مقترح، لم يُطبَّق)، والنص الكامل للصفحة.
- proposals/: مراجعة الحماية (الأقسام 1-13)، وتصميم القيد اليدوي، وسجل فجوة تقرير الأصول (مقترح، لم يُعتمد).
- tests/: المواصفات المستعملة في آخر التشغيلات.
- logs/: نتائج التزامن (ترتيبان، ضابط بلا حارس)، والكتابة المباشرة، وفشل التدقيق، وحالات التشغيل.

## ما لم يُعتمد أو لم يُنفَّذ
- الخيار A للقيود اليدوية: مقترح، لم يُطبَّق، ينتظر قرارك.
- تأجيل تقرير الأصول: مقترح للمراجعة، لم يُعتمد بنص صريح؛ الرابط مُخفى بإجراء سابق بانتظار التأكيد.
- توسيع check_audit_action يبقى بعد التراجع ويغيّر مجموعة القيم المقبولة (PROJECT_UPDATED).
