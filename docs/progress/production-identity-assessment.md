## 3) بيانات/إعدادات يجب الحفاظ عليها — غير قابلة للجرد بلا وصول
لا يمكن الجزم بوجود بيانات اختبار على المشروع السحابي دون قراءة. **استعلام قراءة فقط** يشغّله المالك في Dashboard SQL أو CLI:

```sql
-- test-like tenants (read-only)
select id, name, slug, created_at
from organizations
where slug ~ '(^|[-_])(e2e|smoke|probe|team-org|unbuilt|dups|period|dashboard-bi1)'
order by created_at desc;
-- row counts by key table
select 'organizations', count(*) from organizations
union all select 'journal_entries', count(*) from journal_entries
union all select 'chart_of_accounts', count(*) from chart_of_accounts
union all select 'members', count(*) from members;
```
**سياسة:** تصدير/أرشفة فقط، **بدون حذف**، ثم قرار المالك.
